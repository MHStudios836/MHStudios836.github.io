ZONE 6: THE NERVOUS SYSTEM (Background Services)
These scripts run invisibly across multiple pages.

firebase-init.js: The Heart. Connects to Google Cloud.

auth-guard.js: The Sentry. Kicks you out if you aren't logged in.

notification-hub.js: The Voice. Pops up "Mission Updated" toasts.

global-alert-ticker.js: The News Feed. Scrolls alerts at the top of the screen.

hud-sync.js: The Eyes. Keeps the Wallet $$ in the header updated instantly.

upgrade_firebase.py: The Doctor. Fixes version mismatches in the code.


ZONE 7: CLOUD_INFRASTRUCTURE (The "Nervous System")
  │
  ├── [ NODE: index.js ] ( The Central Cortex )
  │    │── [ROLE]: Trigger Manager
  │    │── [LOGIC]: Imports Sentinel, Overseer, and Banker.
  │    │── [CRON]: exports.dailyReport (Runs every 24h)
  │    └── [ROUTING]:
  │         ├── On Chat Message ─────➤ Trigger [SENTINEL]
  │         ├── On User Update ──────➤ Trigger [OVERSEER]
  │         └── On Mission Create ───➤ Trigger [BANKER]
  │
  ├── [ NODE: sentinel.js ] ( The AI Security Guard )
  │    │── [TRIGGER]: onCreate('chats/{id}/messages/{msgId}')
  │    │── [LOGIC]:
  │    │    1. Scan text for BANNED_WORDS ["scam", "whatsapp", "stupid"]
  │    │    2. IF VIOLATION DETECTED:
  │    │       ├── [WRITE]: Message Text = "🚫 [REDACTED]"
  │    │       ├── [WRITE]: User.stats.warnings += 1
  │    │       └── [DECISION]:
  │    │            └── IF Warnings >= 3 ➤ Set User.is_banned = TRUE
  │    └── [OUTPUT]: Clean Chat Stream / Auto-Banned Users
  │
  ├── [ NODE: overseer.js ] ( The HR Manager )
  │    │── [TRIGGER]: onUpdate('users/{uid}')
  │    │── [LOGIC]: Compare Old_Stats vs New_Stats
  │    │    ├── [PATH A]: STUDENT EVOLUTION
  │    │    │    └── IF tasks_created hits 50 
  │    │    │        └── [WRITE]: unlocked_features.become_freelancer = TRUE
  │    │    │
  │    │    └── [PATH B]: MERCENARY PROMOTION
  │    │         └── IF tasks_completed hits 10 
  │    │             └── [WRITE]: unlocked_features.apply_operator = TRUE
  │    └── [OUTPUT]: Send Notification ("PROMOTION AVAILABLE")
  │
  └── [ NODE: banker.js ] ( The Escrow Agent )
       │── [TRIGGER]: onCreate('missions/{id}') or onUpdate
       │── [LOGIC]: Audit the Mission Price
       │    1. Check Student's Wallet Balance
       │    2. IF Balance < Price ➤ Cancel Mission / Throw Error
       │    3. IF Balance >= Price:
       │       ├── [TRANSACTION]: Wallet -= Price
       │       ├── [TRANSACTION]: System_Vault += Price
       │       └── [WRITE]: Mission.payment_status = 'ESCROW_SECURED'
       └── [OUTPUT]: Mission goes live to Broadcast_Station.html
